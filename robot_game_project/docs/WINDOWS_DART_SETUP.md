# 윈도우 DART-Platform 셋업 가이드 (Claude용 작업 지시서)

> **정정 (2026-11-10)**: 이 문서는 직접 교시가 된다는 전제로 쓰였지만, 그 전제는 매뉴얼로 확인하지 않은 것이었고 틀렸습니다.
> 이 로봇은 티치펜던트도 J6 콕핏도 없어서 직접 교시를 켤 수 없습니다. §2의 6번, §4의 5번, §7의 3~4번은 해당하지 않습니다.
> 보정은 리눅스에서 `robot-calibrate camera-robot --jog --execute-motion`(키보드 스텝 조그)으로 합니다. 셋업 결과와 현재 절차는 저장소 루트의 README.md "실기 준비"를 보세요.

이 문서는 **윈도우 PC에서 Claude와 함께 두산 로봇 초기 셋업을 진행**하기 위한 맥락 전달용입니다.
윈도우 쪽 Claude는 이 문서만 보고 작업을 도와야 합니다. 프로젝트 코드는 윈도우에 없습니다.

---

## 1. 배경

- 로봇: **두산 E0509** 협동로봇. 그리퍼는 **ROBOTIS RH-P12-RN(A)**이고, 그리퍼로 **펜**을 잡아 종이에 그림을 그립니다.
- 프로젝트: 카메라로 종이를 보고 로봇이 틱택토와 미로를 펜으로 그리는 게임(`robot_games`)입니다.
  - 코드, ROS 2 Jazzy, 카메라는 모두 **별도의 리눅스 PC**(Ubuntu 24.04)에 있습니다.
- 이 로봇에는 **하드웨어 티치펜던트가 없습니다.** 비상정지 버튼만 따로 있습니다.
  - 그래서 펜던트 역할을 **윈도우의 DART-Platform**이 대신합니다.
- **윈도우의 역할은 "로봇 설정용 리모컨"뿐입니다.** 코드 실행, ROS, 카메라는 다루지 않습니다.

```
[리눅스 PC] 코드 + ROS 2 + 카메라 + robot-calibrate
      │ LAN
[로봇 컨트롤러] ── 비상정지 버튼
      │ LAN
[윈도우] DART-Platform (이 문서의 작업 범위)
```

## 2. 이번 셋업의 목표

리눅스 쪽 **카메라-로봇 보정**(`robot-calibrate camera-robot`)을 할 수 있는 상태를 만드는 것이 목표입니다.
그 보정은 운영자가 **직접 교시**(로봇 팔을 손으로 끌기)로 펜 끝을 바닥의 ArUco 마커 중심 5곳에 대는 방식이고, 리눅스는 그때의 로봇 좌표를 읽기만 합니다.

이를 위해 윈도우(DART)에서 할 일은 다음과 같습니다.

1. DART-Platform을 설치하고 컨트롤러에 연결
2. 서보 ON, 수동 모드 확인
3. **툴(그리퍼+펜) 무게와 무게중심 등록**: 값이 틀리면 직접 교시 때 팔이 처지거나 밀립니다.
4. **TCP 2개 등록**
   - `pen_tip`: 그리퍼가 잡은 펜의 끝. 그릴 때와 보정할 때 씁니다.
   - `gripper_tip`: 그리퍼 손가락 끝. 펜을 집거나 반납할 때 씁니다.
5. 안전 설정 확인(충돌 감도, 속도 제한, 작업 공간)
6. **직접 교시 모드가 켜지고, 손으로 팔이 부드럽게 움직이는지** 확인
7. 결과값을 리눅스 쪽으로 전달(§6)

## 3. 환경 준비

### 3.1 윈도우 실행 환경 (택1)
- **실물 윈도우 PC**: 가장 간단합니다.
- **리눅스 PC 안의 가상머신**(VirtualBox / KVM): 기계를 늘리지 않아도 됩니다.
  - 네트워크는 반드시 **브리지(bridged)** 모드로 설정하세요. NAT로는 컨트롤러에 연결되지 않을 수 있습니다.
- **맥의 가상머신**: 인텔 맥은 대체로 무난합니다. 애플 실리콘 맥은 ARM용 윈도우의 x86 에뮬레이션이라 DART가 동작하는지 직접 확인해야 합니다.

### 3.2 DART-Platform 설치
- 두산로보틱스 공식 사이트(고객 지원/다운로드)에서 **DART-Platform** 설치 파일을 받습니다.
  - 정확한 URL과 버전은 확인되지 않았습니다. 사용자에게 받은 경로가 있으면 그것을 쓰고, 없으면 공식 사이트에서 찾으세요.
- **컨트롤러 펌웨어 버전과 호환되는 버전**인지 확인합니다. 버전이 맞지 않으면 연결되지 않거나 기능이 빠질 수 있습니다.

### 3.3 네트워크
- 윈도우와 컨트롤러를 같은 스위치/공유기에 랜선으로 연결하거나, 컨트롤러에 직결합니다.
- 컨트롤러 IP: `________` (사용자에게 확인. 모르면 컨트롤러 라벨이나 매뉴얼의 기본값을 확인)
- 윈도우 IP는 컨트롤러와 **같은 대역**의 고정 IP로 설정합니다. 예: 컨트롤러가 `192.168.137.100`이면 윈도우는 `192.168.137.50`, 서브넷 `255.255.255.0`.
- `ping <컨트롤러 IP>`로 연결을 확인합니다.
- 리눅스 PC도 같은 대역에 있어야 합니다. 이미 연결되어 있다면 그 대역을 따르세요.

## 4. DART에서 할 작업 (순서대로)

> 각 단계 전에 **비상정지 버튼이 손 닿는 곳에 있는지** 확인하세요. 로봇 주변에 사람이나 물건이 없어야 합니다.

1. **연결, 서보 ON**: DART로 컨트롤러에 접속 → 서보 ON → 에러나 알람이 없는지 확인. 알람이 있으면 내용을 기록하고 해제 방법을 확인합니다.
2. **툴 무게 등록** (툴 이름 예: `rh_p12_pen`)
   - 무게: 그리퍼 + 펜 + 브래킷의 합계(kg). 그리퍼 카탈로그 값에 펜 무게를 더하거나 저울로 실측합니다.
   - 무게중심: 플랜지 기준 (x, y, z) mm. 대략 그리퍼 길이의 중간쯤에 있습니다.
   - DART에 자동 측정(툴 무게 측정) 기능이 있으면 그것을 우선 사용합니다.
   - 등록한 툴을 **현재 툴로 선택**합니다.
3. **TCP 등록**
   - `gripper_tip`: 플랜지 면에서 그리퍼 손가락 끝까지의 오프셋 (x, y, z, rx, ry, rz).
   - `pen_tip`: 플랜지 면에서 **그리퍼가 잡은 펜의 끝**까지의 오프셋. 펜은 그리퍼 축과 같은 방향으로 잡는다고 가정합니다.
   - 오프셋은 자로 실측합니다. DART에 TCP 자동 측정(한 점을 여러 자세로 찌르기) 기능이 있으면 그것이 더 정확합니다.
   - **TCP 이름은 영문 소문자와 밑줄**만 씁니다. 리눅스 설정에 그대로 적어야 하기 때문입니다.
4. **안전 설정 확인**: 바꾸기 전에 반드시 **사용자에게 확인**받습니다.
   - 충돌 감도: 기본값 이상 유지
   - 협동 모드 속도 제한: 유지하거나 더 낮게
   - 현재 설정값을 기록만 하고, 낮추거나 끄는 변경은 하지 않습니다.
5. **직접 교시 테스트**
   - 직접 교시(핸드 가이딩) 모드를 켭니다. 켜는 방법은 DART 화면 메뉴이거나, 팔 끝에 버튼이 있다면 그 버튼입니다. 어느 쪽인지 확인해서 기록합니다.
   - 팔을 손으로 잡고 여러 방향으로 움직여 봅니다.
     - 놓았을 때 **제자리에 멈추면** 툴 무게 설정이 정상입니다.
     - 아래로 처지거나 혼자 밀리면 툴 무게나 무게중심을 다시 확인합니다.
   - `pen_tip` TCP를 선택한 상태에서 DART가 보여 주는 현재 좌표의 Z가, 펜 끝을 테이블에 댔을 때와 들었을 때 그럴듯하게 바뀌는지 확인합니다.
6. **원상복구**: 테스트 후 직접 교시를 끄고, DART에서 실행 중인 프로그램이 없게 둡니다.

## 5. 하지 말 것

- **DART에서 로봇 프로그램(DRL/Task)을 실행한 채로 두지 마세요.** 나중에 리눅스(ROS)가 로봇에 동작 명령을 보낼 때 권한이 충돌합니다.
- 안전 설정을 **낮추거나 끄지 마세요.** 바꿔야 한다면 사용자 확인을 받고 이유를 기록합니다.
- 컨트롤러 IP를 바꿨다면 반드시 기록하세요. 리눅스 쪽 접속 명령이 그 IP를 씁니다.
- 펌웨어 업데이트는 하지 마세요. 리눅스의 ROS 드라이버(doosan-robot2)와 호환성이 깨질 수 있습니다.

## 7. 이후 (리눅스 쪽에서 할 일, 참고만)

1. `configs/default.yaml`에 TCP 이름을 입력합니다.
2. ArUco 마커 5장(50mm)을 종이 보드 둘레에 붙입니다. 0~3은 모서리 바깥, 4는 한 변 가운데 바깥에 둡니다.
3. DART로 직접 교시 모드를 켠 상태에서, 리눅스에서 `robot-calibrate camera-robot --mode real`을 실행합니다.
4. 펜 끝을 각 마커 중심에 대고 Enter를 누릅니다. 결과는 `configs/camera_robot_calibration.json`에 저장됩니다.
