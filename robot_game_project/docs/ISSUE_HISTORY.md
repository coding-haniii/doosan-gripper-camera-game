## 운영 중 반복된 문제

| 증상 | 대처 |
|---|---|
| 관제실 버튼이 회색(비활성) | bringup이 "RT data is stale" 상태. bringup을 다시 켬 |
| 관제실을 두 개 띄우면 로봇·카메라 충돌 | 이전 창을 닫고 새로 엶 |
| RealSense가 `select() timeout`으로 수십 초 멈춤 | 케이블 고정, 노트북 USB 3 포트에 직결 |

## 남은 일

- 카드 루프(카드를 바꿔 가며 여러 판)는 보류 중입니다.
- RealSense 끊김의 근본 원인(케이블·USB 포트)은 해결하지 못했습니다.
- 펜 집기 위치 미세 조정(Y −10mm 이후 "약간 어긋남")은 확인이 더 필요합니다.
